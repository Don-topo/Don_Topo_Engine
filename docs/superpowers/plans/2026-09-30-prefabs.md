# Prefabs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Unity-style prefabs: `.prefab` assets created from the hierarchy, linked instances with per-property overrides, Apply/Revert/Unpack, propagation, a Lua `Prefab` script property plus `Instantiate(prefab, ...)` with zero disk IO in Play, and export support.

**Architecture:** A prefab is the existing `nodeToJson` output plus a type tag. Instances keep their full subtree in the `.scene`, plus additive link fields (`prefab`, `prefabNode`). Overrides are JSON-Pointer patches detected by diffing an instance against its template at a single point, the undo revision. Core gets a `PrefabLibrary` that preloads templates asynchronously (JobSystem + a dedicated AsyncAssetLoader) into memory-form JSON plus mesh, `.mat` and audio caches. `Scene::instantiatePrefab` builds from that with no IO.

**Tech Stack:** C++20, nlohmann::json, sol2/Lua 5.4, ImGui, JobSystem/AsyncAssetLoader, PhysX, FMOD, Vulkan + D3D12 backends.

**Spec:** `docs/superpowers/specs/2026-09-30-prefabs-design.md` — read it before any task.

## Review Focus

1. **Instance edited while its template is still loading.** The tracker must not recompute overrides against a missing template, or it would wipe the stored list. Test in Task 9.
2. **Apply from one instance while another has an override on the same path.** The other keeps its value (Unity). Test in Task 5.
3. **Prefab file deleted or renamed while the scene is open.** Instances turn red, overrides stay intact, save keeps them. Test in Task 7 (library `Failed` state) and Task 11 (`prefabNodeState` → Missing).
4. **`Instantiate` called in `Awake` of a script on an object created by `Instantiate`.** Reentrancy during a `traverse` must not invalidate iterators: collect first, Awake after. Test in Task 8.
5. **Undo of Create after the user edited the `.prefab` through Apply.** The file must NOT be deleted. Test in Task 10.

```cpp
struct PrefabOverride { uint64_t node = 0; std::string path; nlohmann::json value; };
struct PrefabLink     { std::string path; std::vector<PrefabOverride> overrides; };
nlohmann::json overridesToJson(const std::vector<PrefabOverride>& ovs);
std::vector<PrefabOverride> overridesFromJson(const nlohmann::json& j, std::vector<std::string>* warnings);
// prefabNode / instanceNode: ONE node json each (children ignored). localId = prefab-local id.
std::vector<PrefabOverride> diffPrefabNode(uint64_t localId, const nlohmann::json& prefabNode,
                                           const nlohmann::json& instanceNode, bool isInstanceRoot);

// Returns the overrides that were actually applied (orphans removed).

                                                 const std::vector<PrefabOverride>& ovs,
                                                 std::vector<std::string>* warnings);
}
```

Rules (from spec §2.2 / §3.2):
- Keys never compared: `id`, `name` is compared, `children`, `prefab`, `prefabNode`, `localTransform` (replaced by virtual paths).
- `localTransform` → `/transform/position` `[x,y,z]`, `/transform/rotation` quaternion `[x,y,z,w]`, `/transform/scale` `[x,y,z]` via `glm::decompose` (use the repo's existing decompose helper if `transform_decompose_tests.cpp` covers one; grep `decomposeTransform`). Compare with tolerance 1e-5. For the instance root, position and rotation are skipped.
- A component key (any top-level object key) present in prefab and absent in instance → `{path:"/<key>", value:null}`. Absent in prefab and present in instance → `{path:"/<key>", value:<whole object>}`.
- Present in both: recurse into objects; arrays and scalars are leaves compared exactly (`!=`) and emitted as `{path:"/a/b", value:<instance value>}`.
- JSON Pointer escaping: use `nlohmann::json::json_pointer` to build and resolve (it escapes `~` and `/`).

```cpp
nlohmann::json mat4Json(const glm::mat4& m)

    nlohmann::json a = nlohmann::json::array();

void testDiffDetectsLeafChange()
{

{
    auto p = lightNode(2, 1.0f, glm::mat4(1.0f));
    auto i = p;
    i.erase("light");
    i["rigidbody"] = { {"mass", 2.0} };
    auto d = DonTopo::diffPrefabNode(2, p, i, false);
    bool removed = false, added = false;
    for (auto& o : d) {

{

    root["children"].push_back(lightNode(2, 1.0f, glm::mat4(1.0f)));
    std::vector<DonTopo::PrefabOverride> ovs = {
        {2, "/light/intensity", 3.5},
        {2, "/transform/scale", nlohmann::json::array({2.0, 2.0, 2.0})},
```

### Task 5: Propagation, recompute, unpack

**Files:**

**Interfaces:**
- Consumes: Tasks 1–4.
- Produces:
```cpp
// prefabMemoryRoot: the prefab root node in MEMORY form (resolveStoredPaths applied), local ids.
// Rebuilds instanceRoot = prefab + its stored overrides + its added children. Keeps the scene id of
// every node matched by prefabNode, fresh ids for new nodes, live-id guard afterwards. The old
// subtree goes through removeGameObject (GPU release via onNodeRemoved). Returns the NEW root
// (same id, same parent index) or nullptr on failure (old subtree untouched). Orphan overrides are
// dropped from the link and reported in lastWarnings().
GameObject* rebuildPrefabInstance(GameObject* instanceRoot, const nlohmann::json& prefabMemoryRoot,
                                  PhysicsManager& physics, AudioManager& audio,
                                  const PreloadedMeshCache* meshes = nullptr,
                                  const MaterialAssetCache* mats = nullptr);
// Replaces instanceRoot->prefabLink->overrides with the diff against prefabMemoryRoot. Returns true if
// the list changed. No-op (false) if instanceRoot has no link.
bool recomputePrefabOverrides(GameObject* instanceRoot, const nlohmann::json& prefabMemoryRoot);
// Strips prefabLink and prefabNode from the subtree.
void unpackPrefab(GameObject* instanceRoot);
```

Algorithm for `rebuildPrefabInstance`:
1. `inst = subtreeToMemoryJson(instanceRoot)`. Map `prefabNode → scene id` and collect added children: for each node in `inst` with `prefabNode`, the children WITHOUT `prefabNode` → `added[parentPrefabNode].push_back(childJson)`.
2. `tree = prefabMemoryRoot` (copy). `applied = applyPrefabOverrides(tree, link.overrides, &m_warnings)`.
3. Walk `tree`: `prefabNode = id`; `id = sceneIdByLocal.count(id) ? sceneIdByLocal[id] : erase("id")` (erased → fresh via constructor). Append `added[prefabNode]` to that node's `children`. Set on root: `prefab = {path, overridesToJson(applied)}`; root `localTransform` = instance's (root pose is never an override).
4. Remember `parent`, index of `instanceRoot` in `parent->children`. Build the new subtree with the same machinery as `insertFromJson` (empty root, `carryOverrideBaseline=true`, meshes/mats caches), but BEFORE that call `removeGameObject(instanceRoot)` so its ids are no longer live (the guard would otherwise rename them). If building throws, re-insert the old `inst` JSON with `insertFromJson` at the same index and return nullptr.

`recomputePrefabOverrides`: walk instance nodes with `prefabNode`, find the prefab node by id, concatenate `diffPrefabNode(local, prefabNodeJson, instNodeJson, node == root)`; nodes of the prefab with no instance counterpart → nothing (removing prefab children on instances is blocked in the UI). Added children are not listed as overrides (they are recognized structurally by the missing `prefabNode`), but `hasOverrides()` for the UI = `!overrides.empty() || any added child`.

- **Apply**: read the template's `memoryRoot`; for the chosen overrides apply them to it (`applyPrefabOverrides`); for added children (when included) append their memory JSON with new prefab-local ids `max+1...` and set `prefabNode` on the scene nodes; then `storeRelativePaths` → file JSON → `writeJson`; `lib.updateFromMemory`; remove those overrides from the instance; rebuild every OTHER instance of the same key (they keep their own overrides). Undo writes the previous file bytes back (kept in the command), `updateFromMemory`, restores the instance's overrides/prefabNodes, rebuilds all instances.
- **Revert**: remove chosen overrides (and delete added children when included), `rebuildPrefabInstance`. Undo restores the previous subtree snapshot with `rebuildPrefabInstance` from a stored memory JSON (or delete + `insertFromJson` of the snapshot at the same index).
- **Unpack**: `unpackPrefab`; undo restores the stored `prefabLink` and `prefabNode` per node id.
